# Smart House Gateway

Служба Smart House на хабе: API и живые обновления для приложения Smart House, голосовые команды, правила дома,
удалённый доступ. Работает рядом с ядром на самом хабе, без ноутбука и без интернета для базовых команд.

Хаб из коробки ставится в мастерской; владельцем телефон становится по QR-коду с карточки в коробке — в приложении
Smart House, «Подключить хаб».

## Настройки

- **Файл дома** — `/config/homes/home.json` (на хабе — `/addon_configs/<slug>/homes/home.json`): конфигурация от
  монтажника. Нет файла — пустой дом: комнаты и устройства добавляются из приложения.
- **Заводской ключ** — только для мастерской до запечатывания хаба; обычно пусто.
- **Поднимать Zigbee2MQTT** — хаб сам запускает упавший Zigbee2MQTT; выключать только на время обслуживания.

Порт 5080 — для приложения в домашней сети. Устройство пакета, копии и обновления — `docs/addon.md` в репозитории
проекта.
